# Deployment Guide: The Faux Critic

This guide will help you deploy your application to Vercel with PostgreSQL and Cloudinary.

## Prerequisites

- GitHub account
- Vercel account (free tier is fine)
- Cloudinary account (free tier is fine)

## Step 1: Set up Cloudinary

1. Go to [cloudinary.com](https://cloudinary.com) and sign up for a free account
2. After logging in, go to your Dashboard
3. Note down these three values:
   - **Cloud Name**
   - **API Key**
   - **API Secret**

## Step 2: Deploy to Vercel

### 2.1 Install Vercel CLI (optional but recommended)

```bash
npm install -g vercel
```

### 2.2 Push your code to GitHub

```bash
git add .
git commit -m "Migrate to PostgreSQL and Cloudinary"
git push origin main
```

### 2.3 Deploy via Vercel Website

1. Go to [vercel.com](https://vercel.com) and sign in
2. Click "Add New" → "Project"
3. Import your GitHub repository
4. Vercel will auto-detect it as a Node.js project

### 2.4 Add Environment Variables

In your Vercel project settings, add these environment variables:

**From Cloudinary Dashboard:**
- `CLOUDINARY_CLOUD_NAME` = your cloud name
- `CLOUDINARY_API_KEY` = your API key
- `CLOUDINARY_API_SECRET` = your API secret

**For Database (will add in next step):**
- `POSTGRES_URL` = (will be auto-generated by Vercel Postgres)

### 2.5 Add Vercel Postgres Database

1. In your Vercel project, go to the "Storage" tab
2. Click "Create Database"
3. Select "Postgres"
4. Choose a name (e.g., "faux-critic-db")
5. Select a region close to you
6. Click "Create"
7. Vercel will automatically add the `POSTGRES_URL` environment variable

### 2.6 Redeploy

After adding environment variables, click "Redeploy" in the Deployments tab.

## Step 3: Update Frontend API URL

Once deployed, Vercel will give you a URL like: `https://your-project.vercel.app`

Update your frontend (`app.js` or `index.html`) to use this URL instead of `localhost:3000`:

```javascript
const API_URL = 'https://your-project.vercel.app/api';
```

## Step 4: Test Your Deployment

1. Visit your Vercel URL
2. Upload an image
3. Save to archive
4. Check that images load from Cloudinary (inspect network tab)
5. Test the "Sell Collection" feature

## Local Development

To run locally with the new setup:

1. Create a `.env` file (copy from `.env.example`)
2. Fill in your Cloudinary credentials
3. For local database, either:
   - Install PostgreSQL locally and create a database
   - Or use Vercel Postgres connection string (set `POSTGRES_URL`)

```bash
npm install
npm start
```

## Troubleshooting

### Database connection errors
- Check that `POSTGRES_URL` is set correctly in Vercel environment variables
- Make sure the database was created successfully

### Images not uploading
- Verify Cloudinary credentials are correct
- Check the Cloudinary dashboard for upload quota

### CORS errors
- Make sure your frontend is allowed in CORS settings
- Update CORS configuration in `server.js` if needed

## Cost Estimates

- **Vercel**: Free tier includes 100GB bandwidth/month
- **Vercel Postgres**: Free tier includes 256MB storage, 60 hours compute
- **Cloudinary**: Free tier includes 25GB storage, 25GB bandwidth/month

All free tiers should be sufficient for moderate usage.
